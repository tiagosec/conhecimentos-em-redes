## Subnetting 🌐
#### O que é ? 
Digamos que você tenha uma empresa com vários setores. Se quiser ter um **melhor gerenciamento**, uma **melhor otimização** e **implementação de políticas de segurança**. Tá aí: *segmentação de redes*.
